# Present and export

## Present

**Present** (`F5`) starts at the first slide; **From this slide** (`Shift` `F5`) starts at the one you are on. Double-click a slide in the list to present from it. Hidden slides are left out.

| Key | What it does |
| --- | --- |
| `→`, `Space`, `Page Down` | Next slide |
| `←`, `Page Up` | Previous slide |
| `Home`, `End` | First and last slide |
| `P` | Presenter view: this slide, the next one, your notes and a clock |
| `G` | All slides as a grid; click one to go there |
| `F` | Full screen |
| `B` | A black screen, and back |
| `Esc` | Leave the grid or presenter view, then stop presenting |
| `?` | These keys |

## Export

**Export** on the toolbar offers three files. Each is made from the same drawing as the stage, so what you see is what you get.

| File | What it is |
| --- | --- |
| **PowerPoint (.pptx)** | Editable slides: text boxes, shapes and charts you can change in PowerPoint, the speaker notes, the template's colours and fonts as the file's theme, and your pictures. Hidden slides stay in it, hidden. |
| **HTML (one file)** | The deck as one web page with every picture inside it. It plays in any browser with the keys above, presenter view included. Print it, or save it as PDF, and you get one slide per page. |
| **Speaker notes (.md)** | The notes of every shown slide, in order, as a text file. |

The files go to your Downloads folder. A picture that is only linked, not kept in the file, is left out of the PowerPoint file, and Deck says so.
