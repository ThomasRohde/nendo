# Keys

## In the slide list

| Key | What it does |
| --- | --- |
| `↑`, `↓` | The slide above or below |
| `Shift` `↑`, `Shift` `↓`, `Shift` `Home`, `Shift` `End` | Select more slides |
| `Ctrl` `A` | Select every slide |
| `Ctrl` `↑`, `Ctrl` `↓` | Move the selected slides up or down |
| `Ctrl` `Shift` `↑`, `Ctrl` `Shift` `↓` | Move the selected slides to the start or the end |
| `Home`, `End` | The first or the last slide |
| `Enter`, `Ctrl` `M` | A new slide after this one, in the same layout |
| `Ctrl` `D` | Duplicate the selected slides |
| `Ctrl` `X`, `Ctrl` `C`, `Ctrl` `V` | Cut, copy and paste the selected slides |
| `Delete` | Delete the selected slides |
| `Shift` `F10`, the menu key | The slides' menu |
| `Esc` | Keep only the current slide selected |

## In the slide sorter

The arrows go across and down the rows. `Ctrl` with an arrow moves the selected slides, by a place or by a row. `Enter` opens the current slide, and `Esc` goes back to it.

## In the words on a slide

Click any words on the slide to edit them where they are. Click to place the caret, drag or double-click to select, and type. A right-click, `Shift` `F10` or the menu key opens the text menu: cut, copy, paste, bold, italic, underline, font size, alignment, and bullets and numbering, with the same commands in a small toolbar above it.

| Key | What it does |
| --- | --- |
| `←` `→` `↑` `↓`, `Home`, `End` | Move the caret; with `Shift`, select |
| `Ctrl` `A` | Select all the words in the box |
| `Enter` | A new paragraph; in a list, the next bullet. In a title, a new line |
| `Tab`, `Shift` `Tab` | A bullet one level in or out |
| `Backspace` at the start of a bullet | Takes its level, then its bullet, then joins it to the line above |
| `Ctrl` `Z`, `Ctrl` `Y` | Undo and redo the typing, also after you leave the box |
| `Ctrl` `X`, `Ctrl` `C`, `Ctrl` `V` | Cut, copy and paste, with bold, italic, underline and lists |
| `Ctrl` `Shift` `V` | Paste as plain text |
| `Ctrl` `I`, `Ctrl` `U` | Italic, underline. Bold is in the text menu: `Ctrl` `B` is Nendo's own key |
| `Ctrl` `L`, `Ctrl` `E`, `Ctrl` `R`, `Ctrl` `J` | Align left, centre, right, justify |
| `Ctrl` `]`, `Ctrl` `[` | Larger or smaller text |
| `Esc` | Stop editing the words |

## Anywhere in Deck

| Key | What it does |
| --- | --- |
| `Page Up`, `Page Down` | The slide above or below, when you are not typing |
| `F5` | Present from the first slide |
| `Shift` `F5` | Present from this slide |
| Keys while presenting | See **Present and export**: the next point, the presenter view, the laser, the pen and the timer |
| `Enter` in the ask bar | Send the ask; `Shift` `Enter` starts a new line |
| `Ctrl` `Z`, `Ctrl` `Y` | Undo and redo the last change: words on a slide, or adding, moving, pasting, hiding and deleting slides |

Every change is saved as you type. Nendo's own Undo also takes back adding, moving, deleting and using variants as one step each.
