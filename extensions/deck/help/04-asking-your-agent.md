# Asking your agent

Deck has no agent of its own. It asks the agent you launched from Nendo's Agent page, and Nendo asks you first whether Deck may message it. The ask bar shows only when an agent can be asked.

## Three kinds of ask

| Ask | What the agent does |
| --- | --- |
| **Whole deck** | Writes or changes the deck's slides directly. Use it for "A ten-slide pitch for…", "Add a slide on risks after slide 4", "Write the notes". |
| **This slide** | Leaves the slide alone and writes one to three **variants** of it. Use it for "Make this punchier", "As big numbers", "Shorter". |
| **Mission** | A ready-made job over the whole deck: tighten the story, write speaker notes, rewrite in the brand voice, make every slide fit, or plan the pictures. |

Each ask is a record, written before the agent hears of it. The **Agent** tab lists them with their progress and the agent's reply. The ask bar shows the agent's last progress line while it works, and **Stop** ends its turn.

## Variants

Variants appear under the stage, each drawn as the slide would look. **Use this** puts its words on the slide; the other variants of that slide are dismissed. **Dismiss** sets one aside. Both are one step that Undo takes back. A purple number on a slide in the list says how many variants wait for it.

## What the agent knows

The file carries a skill that tells the agent how Deck works: the layouts and their body grammar, how to write a slide, and how to answer an ask. It reads the deck's **Audience** and **Goal** on the **Design** tab as the brief, and the brand kit's voice when the deck has one. The better the brief, the better the slides.

The agent writes words, never pictures: on a picture slide it writes what the picture should show, and you add it.

## Asking without the ask bar

In any agent session connected to this file, say **"Work the Deck asks"**. The agent finishes every ask that is waiting.
