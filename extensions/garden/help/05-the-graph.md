# The graph

The **Graph** screen draws the whole garden as it really is: each dot a note, each line a link. Notes that link a lot grow larger, and the layout settles itself, pulling linked notes together and pushing the rest apart.

## Moving around

| Do this | And |
| --- | --- |
| Scroll the wheel | Zoom in and out |
| Drag the background | Pan |
| Drag a note | Move it; its neighbours follow |
| Hover a note | Light it and its neighbours, dim everything else |
| Click a note | Open it |
| Right-click a note | Show only its neighbourhood |
| `Ctrl` `0` | Fit the whole garden in view |

## What it can show

The row above the graph has:

- **Find**, to pick out the notes that hold what you type, in their names or their text.
- **Colour** by stage (Seed, Growing, Evergreen) or by kind.
- **Tags**, to add every tag as a small grey dot linked to its notes.
- **Orphans**, to show or hide the notes with no links.
- **Arrows**, to show which way each link points.
- **Spread**, Tight, Normal or Loose, to pack the notes closer or give them room.

Links you or an agent made by hand are drawn dashed; links to tags are dotted.

> The labels fade in as you zoom. Zoomed out, you see the shape of the garden; zoomed in, you read it.

## Without a mouse

`Tab` into the graph and use the arrow keys to move from note to note; `Enter` opens one. A screen reader reads every note with its neighbours as a list.
