# Find your way

As a garden grows, these keep it easy to walk through.

## The tree is the outline

Notes nest: a note can sit under another note, so the garden is one tree rather than folders of files. Click the arrow beside a note to fold its branch away, and again to unfold it. With the keyboard, `→` unfolds a branch or steps into it, and `←` folds it or steps up to the note above.

- **Expand all** and **Collapse all** are in the Note menu of the Garden view.
- Opening a note unfolds the branch it is in, so you always see where you are.
- What you fold is remembered on this device.

To move a note under another, or change its order, use the **Tree** screen and drag it into place.

## Make room

- Drag the line between the tree and the page to widen either. `←` and `→` move it when it has focus; a double-click puts it back.
- Set the page's width with **Narrow**, **Medium** or **Full** in the row above it.

## Read around a note

Under every note, while you read:

- **Backlinks**: every note that links here, with the sentence that does it.
- **Local graph**: this note and every note one link away. Click a dot to go there.
- **Tags** and **Tasks** the note carries.

Hover a link to preview the note it names without leaving the page. Follow it, and Nendo's **Back** brings you back.

## Find a note

**Find** in the row above the page looks through titles and slugs as you type. The tree keeps the branches that hold a match, open or folded.
