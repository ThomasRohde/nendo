# Working with an agent

This garden is built to be read and tended by an AI agent as easily as by you.

## What the agent finds here

The file carries its own instructions for agents, the skill `dev.nendo.garden`. An agent connected to Nendo reads it and learns how this garden works, so you do not have to explain it.

Three things make the garden easy for an agent:

1. **Every note has a slug**, unique in the garden, so `[[for-agents]]` always means one note.
2. **Every note can have a summary**, a paragraph the agent reads instead of the whole body. The hover preview shows it to you too.
3. **Links, tags and tasks are records**, so the agent asks the garden who links where rather than reading every note.

## Things to ask

> "Read my seeds with the most backlinks and draft a first paragraph for each."

> "Find notes about pricing that have no links, and suggest which notes they belong with."

> "Write a summary for every evergreen note that has none."

> "Make a map note for everything tagged #research, linking each note with one line about it."

> "List the open tasks from this week's daily notes, soonest due first."

## Staying in charge

How much an agent may change is yours to set, under **Agent** in Nendo. The skill has an agent write a note's links, tags and tasks as records too, so what it writes looks like what you write, and every change it makes is in **History**.
