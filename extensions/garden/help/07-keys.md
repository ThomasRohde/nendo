# Keys

Everything in the Garden view can be done from the keyboard.

## Writing

| Keys | What they do |
| --- | --- |
| `Ctrl` `E` | Switch between View and Edit |
| `Ctrl` `S` | Save the note |
| `[[` | Open the list of notes to link |
| `↑` `↓`, then `Enter` or `Tab` | Pick a note from that list and put it in |
| `Esc` | Close the list, a preview or the Garden guide |

## Moving around

| Keys | What they do |
| --- | --- |
| `Ctrl` `Shift` `F` | Find a note |
| `↑` `↓` in the tree | Move between notes |
| `→` in the tree | Unfold a branch, or step into it |
| `←` in the tree | Fold a branch, or step up to the note above |
| `Enter` in the tree | Open the note |
| `←` `→` on a divider | Move it; `Home` and `End` take it to its ends |

## In the graph

| Keys | What they do |
| --- | --- |
| Arrow keys | Move to the nearest note in that direction |
| `Enter` | Open the note |
| `Ctrl` `0` | Fit the whole garden in view |
